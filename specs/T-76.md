# T-76 — Guard worker base resolution from the caller's branch

> Frozen spec. Implement this exact unit; report contradictions instead of redesigning.

## Goal
Protect the worker run default base: delegation from a linked worktree must use that worktree's branch, even when the shared main checkout is on another branch.

## Context
WorkerCommands.RunAsync currently discovers the caller's worktree via git rev-parse --show-toplevel, then uses o.Base ?? git branch --show-current ?? HEAD. Git success output is trimmed; failure yields null. The resolved base feeds both cat-file spec validation and git worktree add. CLI tests already have InternalsVisibleTo and HubIsolation points all HTTP at port 1. Follow WorkerReasoningEffortTests and HubIsolationTests patterns.
Base branch: task/T-76-worker-base. Default branch: main. Verify your initial HEAD equals the base, and read this spec with git show from that branch.

## Non-goals
No worker launch, hub, API, catalog, kit, CLI option or detached-HEAD behavior changes. In particular successful empty branch output remains empty, not HEAD. No general dependency injection framework.

## Design
Keep public AddTo(RootCommand) and delegate it to an internal AddTo(RootCommand, IProcessRunner) overload with a new ProcessRunner. Capture that runner in the run action and pass it into RunAsync instead of constructing it there. All existing git/launcher operations in RunAsync use that runner.
Extract only base selection into internal static Task<string> ResolveBaseAsync(IProcessRunner processes, string repository, string? explicitBase, CancellationToken ct). Explicit non-null base returns unchanged without git; otherwise run git branch --show-current in repository with the existing one-minute timeout and ct, returning trimmed stdout on success and HEAD on failure. RunAsync calls this method with its discovered repo and o.Base; preserve every subsequent consumer of baseRef unchanged. Leave other git calls using the existing local helper.
