# T-1 — Dashboard panels: agents, stream, task detail

> Frozen spec. An implementer completes this without making design decisions.
> If something here is wrong or missing, the implementer stops and reports; they do not improvise.

## Goal

The dashboard shell exists (layout, board, stylesheet, `LivePanel` base). `AgentsPanel` and `StreamPanel` are
placeholders and there is no task page. After this task the left column shows every agent live, the stream shows
the ledger as it happens, and clicking any card opens `/tasks/{id}` with the task's full history.

## Context

- Read `CLAUDE.md` first. Dashboard rules: components never touch `MuthurDb`; they call application services.
  Live components inherit `LivePanel`. **Only CSS classes that already exist in `src/Muthur.Server/wwwroot/app.css`
  may be used; do not edit `app.css`, do not add inline styles** (one exception is named below).
- The pattern to copy is `src/Muthur.Server/Components/Panels/BoardPanel.razor` (+ `Shared/TaskCard.razor`,
  `Shared/Format.cs`, `Shared/LivePanel.cs`). Match its structure: `@inherits LivePanel`, `@inject` services,
  private fields, `LoadAsync`, `IsRelevant`, `ClockInterval`.
- Services (all in `Muthur.Server.Services`): `AgentService.ListAsync()` → `IReadOnlyList<AgentDto>`;
  `EventService.ListAsync(long? since, string? taskId, int limit)` → `IReadOnlyList<EventDto>` oldest-first;
  `TaskService.GetAsync(string id)` → `TaskDetailDto`, throws `MuthurException` (`Kind == ErrorKind.NotFound`, or
  `RuleViolation` with code `invalid_task_id`) for a bad id.
- `EventDto.Payload` is a `JsonElement` object. `EventDto.TaskId` is `"T-12"` or null. `LedgerEvent.TaskId` (what
  `IsRelevant` receives) is `int?`.
- `<Virtualize>` renders nothing during prerender, so HTML-level tests cannot see virtualized rows.
- Time: inject `TimeProvider`; never `DateTimeOffset.UtcNow`.

## Non-goals

- No changes to `app.css`, `LivePanel`, `BoardPanel`, `MainLayout`, services, contracts, or the API.
- No "Needs you" page, no message/blocking/inbound filters in the stream (later milestones).
- No actions on the task page (claim/cancel buttons). Read-only.
- No new NuGet packages (no bUnit).

## Design

### Shared: `EventText` and `EventRow` (owned by Unit B)

`src/Muthur.Server/Components/Shared/EventText.cs`

```csharp
namespace Muthur.Server.Components.Shared;

public static class EventText
{
    /// "key: value · key: value" of the payload's non-null scalar properties, in payload order. Max 160 chars, then "…".
    public static string Describe(EventDto e);

    /// "fail" | "warn" | "" — tone of an event type.
    public static string Tone(string type);
}
```

- `Describe`: payload is not an object or has no usable properties → `""`. Strings are used as-is; numbers and
  booleans via `GetRawText()`; `null`, empty strings, objects are skipped; arrays are rendered as their scalar
  items joined by `", "` (empty arrays skipped). Property names are emitted exactly as they appear in the payload.
  Pairs joined by `" · "`. If the result is longer than 160 characters, cut to 159 and append `"…"`.
- `Tone`: `"fail"` when the type ends with `.failed`, `.expired`, `.rejected` or equals `task.claim_expired`;
  `"warn"` when it ends with `.limited`, `.blocked`, `.cancelled`, `.released`; otherwise `""`.

`src/Muthur.Server/Components/Shared/EventRow.razor` — parameters `EventDto Event` (required), `DateTimeOffset Now`,
`bool ShowTask = true`. Markup exactly:

```html
<div class="event">
    <span class="event-age">{Format.Age(Event.At, Now)}</span>
    <div>
        <div class="event-line">
            <span class="event-type event-type-{tone}">{Event.Type}</span>   <!-- omit the second class when tone is "" -->
            <span class="event-actor">{Event.Actor}</span>
            <a class="event-task" href="/tasks/{Event.TaskId}">{Event.TaskId}</a>   <!-- only when ShowTask && TaskId != null -->
        </div>
        <div class="event-detail" title="{describe}">{describe}</div>
    </div>
</div>
```

### Unit A markup — `AgentsPanel`

```html
<section class="panel">
    <div class="panel-head">
        <span class="panel-title">Agents</span>
        <span class="panel-sub">{live} live of {total}</span>
    </div>
    <div class="panel-body">
        <!-- when total == 0 -->
        <div class="empty">no agents registered · muthur agent register --name …</div>
        <!-- per agent -->
        <div class="agent agent-stale|agent-limited">        <!-- modifier only for those statuses -->
            <div class="agent-head">
                <span class="dot"></span>
                <span class="agent-name">{Name}</span>
                <span class="tag">{Tier}</span>                 <!-- only when Tier != null -->
                <span class="agent-age">{Format.Age(LastHeartbeat, now)}</span>
            </div>
            <div class="agent-model">{Harness}/{Model}{" · " + Account when Account != null}</div>
            <div class="agent-summary">{Summary}</div>          <!-- only when Summary is not null/whitespace -->
            <div class="agent-meta">                            <!-- only when it would have at least one child -->
                <span class="pill pill-role">{role}</span>      <!-- one per role -->
                <span class="pill">{OpenTasks} task|tasks</span><!-- only when OpenTasks > 0; singular for 1 -->
                <span class="pill pill-blocked">limited {Format.Until(LimitedUntil, now)}</span> <!-- only when Status == Limited -->
            </div>
        </div>
    </div>
</section>
```

- Order: `Live`, then `Limited`, then `Stale`; by `Name` within a status.
- `IsRelevant`: event type starts with `agent.`, `role.` or `task.`.
- `ClockInterval`: 15 seconds (staleness changes with time alone).

### Unit B markup — `StreamPanel`

- Parameter `bool Compact`. Loads `EventService.ListAsync(null, null, Compact ? 80 : 500)` and shows **newest first**.
- Filters (client-side over the loaded list), buttons in the panel head:
  `All` (default) · `Tasks` (type starts with `task.`) · `Agents` (type starts with `agent.` or `role.`).

```html
<section class="panel">
    <div class="panel-head">
        <span class="panel-title">Stream</span>
        <span class="panel-sub">{filtered count} events</span>
        <div class="filters">
            <button class="filter active" @onclick=…>All</button>    <!-- "active" on the selected one only -->
            <button class="filter" …>Tasks</button>
            <button class="filter" …>Agents</button>
        </div>
    </div>
    <div class="panel-body">
        <Virtualize Items="…" Context="e" ItemSize="44" OverscanCount="10"><EventRow Event="e" Now="_now" /></Virtualize>
        <div class="empty">nothing yet</div>       <!-- only when the filtered list is empty -->
    </div>
</section>
```

- `Virtualize.Items` needs an `ICollection<EventDto>`; keep a `List<EventDto>` for the filtered view and rebuild it
  in `LoadAsync` and when the filter changes.
- `ClockInterval`: 30 seconds (ages tick). `IsRelevant`: everything (default).

### Unit C — `TaskDetail` page

`src/Muthur.Server/Components/Pages/TaskDetail.razor`, `@page "/tasks/{Id}"`, `@inherits LivePanel`,
`<PageTitle>MUTHUR · {Id}</PageTitle>`.

- `LoadAsync`: call `TaskService.GetAsync(Id)`; catch `MuthurException` → set the detail to null and remember the
  message. `IsRelevant`: `e.TaskId` equals the numeric part of `Id` (use `Wire.TryParseTaskId`). `ClockInterval`: 30 s.
- Blazor reuses the component when navigating `/tasks/T-1` → `/tasks/T-2`: override `OnParametersSetAsync` and
  reload when `Id` changed since the last load.
- Not found / invalid id:

```html
<div class="page"><section class="panel panel-fit"><div class="panel-body"><div class="empty">{exception message}</div></div></section></div>
```

- Found:

```html
<div class="page">
    <section class="panel panel-fit">
        <div class="panel-body">
            <div class="detail-head">
                <span class="card-id">{Id}</span>
                <h1 class="detail-title">{Title}</h1>
                <span class="pill pill-owner">{State.ToWire()}</span>
                <span class="pill pill-priority">priority {Priority}</span>        <!-- only when Priority > 0 -->
                <span class="pill pill-verdict-{Verdict}">{Validator} {Verdict}</span>  <!-- one per validation -->
            </div>
            <dl class="kv" style="margin-top: 12px">     <!-- the one permitted inline style -->
                Project · Owner ("—" when none; append " · lease {Format.Until(ClaimExpires, now)}" when ClaimExpires != null)
                · Spec · Branch · Pull request (as <a href> when present) · Parent (as <a href="/tasks/{Parent}">)
                · Created · Updated · Done
            </dl>
        </div>
    </section>
    <section class="panel panel-fit">
        <div class="panel-head"><span class="panel-title">Description</span></div>
        <div class="panel-body"><div class="prose">{Body}</div></div>      <!-- <div class="empty">no description</div> when Body is blank -->
    </section>
    <section class="panel">
        <div class="panel-head"><span class="panel-title">History</span><span class="panel-sub">{n} events</span></div>
        <div class="panel-body">{EventRow for each event, oldest first, ShowTask="false"; NOT virtualized}</div>
    </section>
</div>
```

- `kv` rows are `<dt>Label</dt><dd>value</dd>`. Rows whose value is null are omitted entirely (Spec, Branch,
  Pull request, Parent, Done). Timestamps: `value.ToLocalTime().ToString("yyyy-MM-dd HH:mm")`.
