## Design
Only modify tests/Muthur.Launch.Tests/CapabilityProbeTests.cs.
1. Change the fixture to xUnit IAsyncLifetime (completed InitializeAsync, asynchronous DisposeAsync). Keep existing directory creation. DisposeAsync must first establish that all real runner calls finished with confirmed ownership, then remove any fixture-owned retained registered worktrees through a real git worktree remove --force --force invocation; finally normalize owned file attributes, delete the root, and assert it no longer exists. A failed command or deletion fails cleanup; no catch-and-ignore or retries. Teardown must bypass the simulated cleanup failure so it does not confuse test-owned disposal with production reservation recovery. Never release the fake retained reservation from teardown.
2. Within FixtureRunner route ALL three existing _real.RunAsync paths through one private async wrapper that records started/completed real calls, in-flight count, and whether any call threw ProbeCleanupUncertainException. In-flight decrement is in finally; a returned result or ordinary exception means the production runner's finally confirmed exit. An uncertain real call must make fixture cleanup fail with a useful diagnostic, not permit blind deletion. Expose read-only values needed for assertions. Include command/working-directory context for failed cleanup diagnostics without dumping environment values. No new production testing hooks.
3. Record successfully added worktree paths from actual git worktree add calls, and distinguish simulated worktree remove attempts from real removal. Before acting on any recorded worktree in teardown verify its fully resolved path lies under this test's _root/scratch boundary; do not discover or delete other repositories/worktrees. For recorded paths already removed by production, assert absence and skip them. For still-existing paths invoke the real wrapper with git -c core.hooksPath=NUL (or /dev/null) -c core.fsmonitor=false -c submodule.recurse=false -c diff.external= worktree remove --force --force <path>, working directory _root, isolated global/system Git config as in existing fixture. Timeout 10 seconds, then assert successful result and directory absence. Finally git worktree list --porcelain for the root repository must contain no recorded retained worktree. Do not run git listing for a fixture that never initialized its repository. Keep reparse-point handling from production untouched; no recursive traversal into links added by the fixture.
4. Strengthen Uncertain_cleanup_retains_reservation_and_never_publishes_cache before teardown: exactly one simulated model invocation, all real commands completed and none uncertain/in-flight, exactly one existing recorded worktree, retained reservation (zero releases), no cache, original exception shape. process-cleanup must have zero worktree-remove attempts; cleanup must have exactly one simulated remove failure. This proves production preserved scratch as required and test-owned cleanup has separate ownership. Preserve all existing tests and assertions.
5. Add a two-case theory for test-owned cleanup of the two uncertainty modes that explicitly invokes the same fixture cleanup method after the above invariants, asserts the root/worktree are absent and the reservation remains unreleased, then permits automatic DisposeAsync to be a no-op only because successful cleanup was already recorded. Do not mark cleanup complete on failure. Factor the existing uncertainty assertions to avoid drifting duplicate logic. Also assert real calls started equal completed, with nonzero count; counters are observation, not a replacement for process runner guarantees.
6. Ensure cleanup is performed by DisposeAsync even when a test assertion fails. Include a short comment explaining simulated uncertainty versus real process ownership. Avoid claiming this identifies the historic lock holder.
