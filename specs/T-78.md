# T-78 — Preserve and document harness identifier casing

> Frozen spec. Implement exactly; report a spec problem rather than redesigning.

## Goal
Registration retains the caller's harness identifier after trimming surrounding whitespace. Custom case-sensitive kit and catalog names can be registered, and callers can read this rule in CLI help and the API contract.

## Context
AgentService.RegisterCoreAsync currently applies Trim().ToLowerInvariant() to Harness. DoctorAgentCheck deliberately compares kit directory names and catalog candidate harnesses with StringComparer.Ordinal. KitDirectory preserves directory names. T-61 accepts unknown harnesses intentionally and reports problems through doctor. Its DoctorAgentTests case-mismatch test currently works around registration folding. Preserve that permissive registration and ordinal doctor behavior. Follow CLAUDE.md and existing AgentTests/DoctorAgentTests patterns.
Base: task/T-78-harness-case, originally main at 6cf2fb3. Verify git log and ancestry against main before work; report stale or unexpected base.

## Non-goals
No case-insensitive kit/catalog changes, name or tier normalization changes, adapter matching changes, schema migration, historical ledger rewrite, new validation restriction, or console redesign.

## Design
- AgentService.RegisterCoreAsync assigns request.Harness.Trim(), preserving exact casing for public registration, authorized re-registration and conductor registration.
- Existing persisted rows remain byte-for-byte unchanged until explicitly re-registered; lost original casing cannot be recovered. Lowercase callers retain existing behavior. No migration.
- AgentDto, registration response, roster, identity and ledger payload all expose that trimmed, case-preserved stored harness via existing mapping.
- Unknown nonblank harnesses remain accepted; blank harness/model still yields existing harness_required error. Name/tier normalization, token rotation and authorization remain unchanged.
- RegisterAgentRequest gets XML documentation explaining surrounding whitespace is trimmed, case is preserved, unknown identifiers are allowed, and kit/catalog identifiers must match case for doctor checks.
- AgentCommands --harness description: "Agent harness (e.g. claude, codex). Whitespace is trimmed; case is preserved. Match kit/catalog spelling exactly."
- Add a short README registration note with the same rule and compatibility guidance: existing rows are unchanged; re-register an existing agent as itself or founder to correct casing previously folded. Do not imply adapter lookup or all Windows filesystem access becomes case-sensitive.
