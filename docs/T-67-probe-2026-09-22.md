## T-97: one real Claude Agent-tool unit in the founder's normal permission mode

Run from this Claude Code session (auto permission mode, Windows 11, PowerShell 7) by spawning the `muthur-implementer`
agent type on the same PROBE.md spec, in its own worktree `agent/t-97-probe`, commit acfbf64.

| # | Command | Decision | Prompt | Result |
|---|---|---|---|---|
| pre | `git worktree add ... -b agent/t-97-probe main` | allowed | no | exit 0 |
| 1 | `git status`, `git branch --show-current` | allowed | no | exit 0 |
| 2 | `dotnet --version` | allowed | no | 10.0.103 |
| 3 | Write `hello.txt` | allowed | no | created |
| 4 | `git add`, `git commit` | allowed | no | acfbf64 |
| 5 | `gh --version` | **allowed** | no | gh 2.28.0 |
| 6 | `git push` | **allowed**, failed | no | exit 128, no remote configured |
| x | `dotnet build` in an empty tree | allowed | no | MSB1003 as expected |

Nothing prompted and nothing was denied. The `muthur-implementer` definition excludes `Bash(git push *)` and
`Bash(gh *)`, but the subagent ran every command through the **PowerShell** tool, which those `Bash(...)` deny rules do
not cover. Nothing was published (the scratch repo has no remote), but the finding stands:

- **On Windows, the native Agent-tool rails in `.claude/agents/*.md` do not deny push or gh when the PowerShell tool is
  available.** The deny list must be duplicated as `PowerShell(git push *)` / `PowerShell(gh *)` (and the other
  patterns) or the PowerShell tool must be excluded from those agents. This is the permission-provisioning proposal
  T-97 was to bring to the founder; applying it touches protected agent definitions and stays attended (T-88).
- The `worker run` path (T-67 above) is unaffected: it renders its own settings file for a `claude --print` process and
  denied `gh` outright.
- Compare with the historical baseline in `docs/claude-agent-permissions.md`: earlier unattended sessions saw dotnet
  and mutating git denied. In this session's auto mode nothing was denied at all, so permission behaviour is a
  property of the initiating session's mode, as that document predicted.
